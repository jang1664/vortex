# `VX_gpu_pkg.sv` — 파일 요약

요약
- 공통 타입, 구조체, 상수, 파라미터를 정의하는 패키지 파일입니다. GPU 스타일 아키텍처 전반에서 사용되는 데이터 타입과 유틸리티가 들어있습니다.

주요 내용(예상)
- 워프/스레드 관련 파라미터(`NUM_THREADS`, `NUM_WARPS` 등).
- 공통 패리티/태그/아이디 타입, `VX_mem_bus_if` 등 인터페이스 타입 정의(혹은 인터페이스는 별도 파일에 있을 수 있음).

읽기 포인트
- 타입 정의(typedef), enum, 구조체, 및 공용 파라미터 목록.
- 패키지를 임포트(import)하는 다른 파일에서 어떤 심볼을 쓰는지 확인.

비고
- 패키지 자체는 동작을 직접 구현하지 않으므로 다른 모듈을 읽을 때 참조되는 타입을 중심으로 파악하세요.
