# `core/VX_execute.sv` — 파일 요약

요약
- 실행(execute) 스테이지를 구현하며 ALU, FPU, SFU 등 실제 연산 유닛을 호출하고 결과를 취합합니다. 또한 예외/인터럽트 처리를 위한 상태 업데이트를 수행합니다.

주요 인터페이스(추정)
- 발행으로부터의 인수 및 제어 신호, 결과를 레지스터 파일 또는 writeback 경로로 전달.

주요 동작
- 연산 유닛별 파이프라인 제어, 연산 대기 및 결과 조합.

읽기 포인트
- 각 연산 유닛(ALU/FPU/SFU) 호출 및 결과 합성, 예외 플래그 처리.
