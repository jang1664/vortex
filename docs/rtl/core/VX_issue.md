# `core/VX_issue.sv` — 파일 요약

요약
- 명령 발행(issue) 관련 로직을 담당합니다. 디스패치된 uop들을 실행 유닛으로 보내기 전 스케줄링, 자원 확인, 스코어보드와의 상호작용을 처리합니다.

주요 인터페이스(추정)
- 디코드/디스패치로부터의 uop 입력, 실행 유닛(alu/lsu/fpu 등)으로의 발행 출력.
- 스코어보드/스케줄러와의 상태 신호.

주요 동작
- 대기 중인 uop의 종속성 해소 확인, 발행 우선순위 결정, 발행 트리거.

읽기 포인트
- 스코어보드 체크 로직, 발행 우선순위/페어링 알고리즘.
