# `VX_socket.sv` — 파일 요약

요약
- 외부 통신(예: 메모리 소켓, 호스트 I/O) 추상화를 제공하는 소켓/인터페이스 레이어입니다. 플랫폼(시뮬레이터/실제 HW)과의 연결을 단순화합니다.

주요 인터페이스(추정)
- 소켓 초기화/전송/수신 신호들.
- 상위 모듈이 기대하는 요청/응답 포맷(예: `mem_req`/`mem_rsp`).

읽기 포인트
- 소켓 API(포트 선언)와 데이터 포맷 매핑부.
- 플랫폼 별 구현 분기(`#ifdef` 등) — 시뮬레이터/실제 HW 대응 로직.

비고
- 이름으로 미루어 보아 중간 어댑터 역할이 크므로 외부 드라이버와의 경계를 이해하는 데 유용합니다.
