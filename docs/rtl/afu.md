# `afu/` 디렉터리 요약

`afu/` 디렉터리는 Accelerator Function Unit(가속기 함수 유닛) 관련 구현과 플랫폼별 어댑터를 포함합니다. 런타임/시뮬레이터 백엔드(opae, xrt 등)와의 연동 코드가 이곳에 위치합니다.

주요 항목
- `opae/`: OPAE(Accelerator runtime) 관련 어댑터 및 래퍼 구현.
- `xrt/`: XRT와 연동되는 코드 및 테스트/시뮬레이션 어댑터.

역할
- 호스트 런타임과의 인터페이스를 담당하며, AFU 특유의 프로토콜을 구현합니다.
- 시뮬레이션 및 실제 런타임 간 차이를 흡수하는 어댑터/스텁을 제공합니다.

다음 학습 포인트
- AFU와 메모리/버스 인터페이스가 어떻게 연결되는지 확인 (예: AXI/AVS 어댑터 사용 위치).
