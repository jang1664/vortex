# Project Context

Load project context for subagents. Read `CLAUDE.md` and follow the **Common** and **Subagent Only** sections. Ignore the **Main Agent Only** section.

## Steps

1. Read `CLAUDE.md` at the project root.
2. Follow rules under "Rules — Common" and "Rules — Subagent Only".
3. Use the "Reference Map (Common)" to find relevant documentation for your task.
4. Do NOT follow rules under "Rules — Main Agent Only" — those apply only to the main agent.
