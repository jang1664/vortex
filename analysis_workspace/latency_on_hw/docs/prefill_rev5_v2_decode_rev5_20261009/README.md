# Prefill Rev5_v2 / decode Rev5 figures

Prefill uses Rev5_v2; decode retains historical Rev5, including its omission of standalone head-reorder/V-transpose costs. These stages do not have identical cost accounting.

All 24 prefill and 72 decode candidate rows per input were checked against their respective sources; missing columns from older sources remain empty (zero-valued components for plotting). See manifest.json for paths, SHA256 hashes and calculated ranges.
